# Number Guessing Game
## Description
This is a simple C++ game where the player tries to guess a randomly generated number. The game gives hints if the guess is too high or too low.
## Features
- Random number generation
- Hint for each guess
- Counts the number of attempts
## Technologies Used
- C++

# Tic Tac Toe
## Description
A simple two-player Tic Tac Toe game developed using C++. Players take turns to mark X and O until one player wins or the game ends in a draw.
## Features
- Two-player game
- Winner detection
- Draw detection
## Technologies Used
- C++
